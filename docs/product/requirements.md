# Phase 1 Requirements

| ID | Requirement |
|---|---|
| CL-TAXONOMY-001 | Configure curricula, editions, grades, subjects, chapters, and topics. |
| CL-TAXONOMY-002 | Block deletion of referenced taxonomy values and prevent cascading deletes. |
| CL-TAXONOMY-003 | Deactivate taxonomy values without removing historical data. |
| CL-TAXONOMY-004 | Clone an edition or subtree as a draft without copying activity. |
| CL-TAXONOMY-005 | Configure permitted taxonomy level types in a lookup registry. |
| CL-TAXONOMY-006 | Reject unregistered levels and invalid parent-child relationships. |
| CL-TAXONOMY-007 | Add optional hierarchy levels without changing historical editions. |
| CL-TAXONOMY-008 | Enforce one default active edition per curriculum and grade. |
| CL-QBANK-001 | Author and validate single-select questions. |
| CL-QBANK-002 | Author and score exact-match multiple-select questions. |
| CL-QBANK-003 | Classify questions by taxonomy, difficulty, type, language, and workflow state. |
| CL-AI-001 | Generate original AI-assisted drafts with mandatory human review. |
| CL-COPYRIGHT-001 | Record provenance and apply similarity checks before publication. |
| CL-PRACTICE-001 | Practice in batches and resume incomplete sessions. |
| CL-PRACTICE-002 | Bookmark questions and review mistakes and explanations. |
| CL-ANALYTICS-001 | Report accuracy and average response time by taxonomy. |
| CL-AUTH-001 | Submit signup requests for configured email approval before creating Keycloak student accounts. |
| CL-AUTH-002 | Allow administrators to disable signup approval through configuration. |
